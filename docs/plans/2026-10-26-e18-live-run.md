# E18 round 1: the first live one-command run (build plan, 2026-10-26)

Intent: prove the round end to end. One `/ship-v2 A` on this plan, typed by the owner in a fresh window after the reinstall, should build, sign off in its own fresh session, fix and recheck to the end with no second window (C-29). The slice is kept small and safe on purpose: a docs gap in ship-v2 with an automated check, so the run never stops for a manual step and nothing live is at risk.

Source: E18 Slice C's discovered note: `plugins/ship-v2/skills/ship-v2/adapters/README.md` does not list `launch.py`. The owner asked for a candidate slice and gave the go to draft this one ("yes, draft it", 2026-10-26).

Constraints:

- The repo is public: no secrets, personal paths, mail addresses, key-shaped strings or em dashes in any file. This plan's slice heading uses a plain hyphen, which every installed station now reads (E18 Slices A and B).
- Never rewrite stored history: earlier verdict docs, records, run directories, plans, `RESULTS.md` files, setups records and measured counts that say when they were measured stay as they are.
- Each check is one line, `<name>: <command>`, the command run from the repository root and reported under exactly that text (build-v2 matches it). The name holds no colon.
- The two signoff-v2 adapter suites run alone, never beside another suite (their helper starts a nested `uv run` that breaks under contention). Other suites may run up to four side by side, each a different suite.
- No version bump in this plan: the catalog carries no versions, and a docs-only change to one README needs no update on any machine.
- No push, no PR, no merge: the owner's word only.
