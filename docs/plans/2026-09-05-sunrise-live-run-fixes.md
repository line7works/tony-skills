# sunrise-live-run-fixes — build plan (2026-09-05)

Intent: Two defects in `/sunrise` surfaced by its first live run after the agent-file flip (project Banana Dunk, slug `banana-dunk`, archetype static, 2026-09-05, sun plugin cache `75b836b0c1ff`). First, `npx vercel link --yes` derives the Vercel project name from the directory `<Name>`, and Vercel rejects mixed case (`Banana-Dunk`, HTTP 400); the run had to be redone with `--project banana-dunk`. Second, `vercel link` appends `.vercel` and `.env*` to the end of `.gitignore`, below the `!.env.example` negation Phase 1 step 3 added, so `.env.example` is ignored again; it stayed tracked in the test only because it was already committed and was fixed by hand. This build makes the skill pass the slug explicitly and re-assert the negation after linking, so the next sunrise does not need a hand fix at either point. For Tony, who runs `/sunrise` once per new project and expects a green baseline without intervention. Source of every requirement: the two 2026-09-05 Inbox notes in `docs/feedback.md` (findings A and B, tagged `sunrise live run (Banana Dunk) · sunrise`) and the current text of `plugins/sun/skills/sunrise/SKILL.md`.
