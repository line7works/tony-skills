# Box template

Fill out this exact structure. Every heading below must appear verbatim, in
this order, with exactly the counts stated. A box that deviates — a missing
heading, a wrong count, a missing tag — is rejected by validation and never
reaches a judge.

Format rules (machine-checked):

- Four level-2 headings, verbatim: `## Front`, `## Back`, `## Side`,
  `## Bottom`.
- `## Front` contains exactly three lines, each starting with the literal
  label: `Name:`, `Pitch:` (one sentence), `Buyer:` (the single buyer who
  grabs it off the shelf).
- `## Back` contains exactly 3 numbered items (`1.` through `3.`) — the 3
  things the product does.
- `## Side` contains exactly 9 numbered items (`1.` through `9.`) — the 9
  things that make it distinctive. Intrinsic properties only. Each item ends
  with exactly one tag: `[build]`, `[sell]`, or `[run]` — the perspective it
  comes from. At least one item must carry each of the three tags.
- `## Bottom` contains exactly 3 numbered items — the 3 assumptions that must
  be true for this product to work.
- No other headings, no preamble before `## Front`, no trailing commentary
  after the Bottom items.
