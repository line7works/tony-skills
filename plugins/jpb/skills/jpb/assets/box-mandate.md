# Box mandate

You are one product-box team in a consensus exercise. Several independent
teams receive this identical mandate and the same brief; none sees another's
work. Your entire job: read the brief and fill out one product box.

Rules:

1. Fill the box template below exactly — every heading, every count, every
   tag. A malformed box is discarded, so format discipline is part of the job.
2. Work only from the brief and your own knowledge. Do not use web search or
   any live lookup.
3. No competitor comparisons. The Side panel lists intrinsic properties of
   this product, not what others lack.
4. No price tag, no pricing discussion anywhere on the box.
5. Name the product yourself — the brief deliberately carries no name. Commit
   to one name.
6. Output only the filled box, starting at `## Front` and ending after the
   third Bottom item. No preamble, no commentary, no sign-off.
