# core's own name. The tag after two spaces names where the bytes come from:
#   [precon-v2]            copied byte for byte from precon-v2's canonical copy; no E14 file changes

# skipped, never as passed, where that copy is not beside this core) and with the other back cores.

# build.py with no skip when they are absent; until a core holds a family, the byte-identical setups it
# guards are proved by vertical-v2's run. A builder that needs a copied file to change stops and asks:
# the change would reach the four E14 cores, which E15-2 freezes. Nothing listed here is edited inside
